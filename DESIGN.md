# Design Direction — Yourtube

Status: confirmed perfect as-is. No visual changes requested.

Identity: personal archive / interactive memory.
Voice: reflective, editorial, slow discovery.

Palette (existing, locked):
- Background: `#140E14` (deep film), `#1C131C` (section ground)
- Cream text: `#F0EBD8`
- Subtle: `#C0B0A0`
- Accent: `#8A5A3A` (terracotta)
- Noise texture: 256px fractal noise overlay at 4% opacity

Typography:
- Display / editorial headings: Playfair Display (serif), tight tracking
- Body / UI: system sans-serif, small uppercase tracking for labels

Layout rules:
- Sticky hero on landing (`/`), scroll-triggered reveal
- Responsive, mobile-first spacing
- No glassmorphism, no generic AI patterns
- Every interactive element must work (R-26)

Dials (locked):
- ENERGY 1 (calm, linear flow)
- RHYTHM 2 (uniform sections with deliberate breaks)
- MOTION 1 (hover states, minimal scroll triggers)

No design changes for current feature build. Read-only exploration features only.
